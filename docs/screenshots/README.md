# README screenshots

These images were captured from a temporary demo workspace under `/tmp` with
fabricated recordings ("SauceDemo" and an example feedback form). They contain
no real project names, account data, or local paths.

Regenerate with the standalone panel:

```bash
# from the repository root, with a demo workspace prepared
node dist/cli.mjs panel --root /tmp/dsh-record-replay-demo --port 4174
# then capture /panel/ with Playwright
```
